# AI Usage Report

## Tools Used

### ChatGPT
Used for:
- Scheduling and planning the assignment
- Structuring the development process (HTML → JS → CSS)
- Design discussions (layout, typography, color palette)
- Generating the README file

### Claude
Used for:
- Generating initial code skeletons for HTML, CSS, and JS
- Refining the interface and section details
- Improving structure and personalization

---

## Code Skeleton Prompt

give me the skeleton for the html. css, and js code with comments to guide coding for a personal portfolio that has a formal but friendly vibe. i want the following sections: home, about, experience(in a timeline form), projects as cards, and a contact form. for design, i want to use cream, navy blue, and orange and cormorant font for headings and poppins for body text. for features, i want smooth scrolling and highlighted nav text based on active section.

## Workflow

1. Used ChatGPT to break down and schedule the assignment tasks.
2. After deciding on layout and features, requested a structured development plan.
3. Claude generated initial code skeletons.
4. I completed and modified the implementation.
5. Claude helped refine and personalize sections.
6. ChatGPT helped generate the README file.
