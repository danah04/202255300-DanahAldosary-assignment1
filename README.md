# Assignment 1 – Personal Portfolio Website

## Overview

This project is a responsive personal portfolio website built using HTML, CSS, and JavaScript.

It acts as a visual CV that presents my background, experience, projects, and contact information in a clean and structured layout. The design follows a modern minimal style with a formal but friendly tone.

Design inspiration:
https://dribbble.com/shots/26844524-Personal-portfolio-website-header

---

## Features

### Sections
- Home (Hero introduction)
- About Me
- Experience (visual timeline)
- Projects (card layout)
- Contact (form with validation)

### Interactivity
- Smooth scrolling navigation
- Active navigation highlight based on visible section
- Mobile navigation toggle
- Contact form validation with feedback

### Responsive Design
- Fully responsive on desktop, tablet, and mobile
- Built using CSS Grid and Flexbox
- Tested using browser DevTools

---

## Technologies Used

- HTML5
- CSS3 (custom properties, Grid, Flexbox)
- JavaScript (DOM manipulation and event handling)
- Google Fonts (Cormorant Garamond + Poppins)
