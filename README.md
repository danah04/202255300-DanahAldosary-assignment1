# Assignment 3 – Advanced Portfolio Website

## 📌 Project Description
This project is an enhanced personal portfolio website developed for Assignment 3.

It builds on previous assignments by adding advanced functionality such as API integration, complex logic, and state management, while maintaining a clean and responsive design.

It acts as a visual CV that presents my background, experience, projects, and contact information in a clean and structured layout. The design follows a modern minimal style with a formal but friendly tone.

Design inspiration:
https://dribbble.com/shots/26844524-Personal-portfolio-website-header

---

## Features

### Core Sections
- Home (Hero introduction)
- About Me
- Experience (timeline)
- Projects (card layout)
- Did You Know? (API feature)
- Contact (form with validation)

### Advanced Functionality

#### API Integration
- “Did You Know?” section fetches random facts from an external API
- Users can load new facts dynamically
- Includes error handling

#### Complex Logic
- Project filtering by category and level
- Sorting projects by year
- Conditional messages based on user selection

#### State Management
- Dark mode toggle
- Theme preference saved using `localStorage`

#### Form Validation
- Required fields
- Email format validation
- Minimum message length check

---

## Technologies Used

- HTML5
- CSS3 (custom properties, Grid, Flexbox)

This project integrates an external API to display random facts in a “Did You Know?” section. Users can generate new facts dynamically, and error handling ensures a message is shown if the API fails.
